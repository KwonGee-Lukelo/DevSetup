# 💻 DevSetup

> Configuration de mon premier environnement de développement dans le cadre de ma formation Fullstack chez Akieni Academy.

---

## Description

DevSetup est un projet d'initiation dont l'objectif est de mettre en place un environnement de développement professionnel.

Ce dépôt documente les différentes étapes de configuration des outils indispensables au développement web moderne ainsi que les premières manipulations avec Git et GitHub.

---

## Objectifs

- Installer Visual Studio Code
- Configurer Git
- Créer un compte GitHub
- Comprendre les bases du terminal
- Créer un premier dépôt Git
- Réaliser les premiers commits
- Publier un projet sur GitHub

---

## Outils utilisés

- Visual Studio Code
- Git
- GitHub
- Git Bash
- Markdown
