# Notes sur GitHub

## Qu'est-ce que GitHub ?

GitHub est une plateforme d'hébergement de dépôts Git.

Elle permet de sauvegarder les projets en ligne, de collaborer avec d'autres développeurs et de présenter son travail.

---

## Pourquoi utiliser GitHub ?

- Sauvegarder ses projets
- Partager son code
- Collaborer avec une équipe
- Construire un portfolio
- Montrer ses compétences aux recruteurs

---

## Workflow GitHub

```text
Créer un dépôt
        ↓
Cloner ou connecter le projet
        ↓
Développer
        ↓
Commit
        ↓
Push
        ↓
GitHub
```

---

## Commandes principales

### Ajouter le dépôt distant

```bash
git remote add origin URL_DU_REPO
```

---

### Envoyer les commits

```bash
git push origin main
```

---

### Télécharger les modifications

```bash
git pull origin main
```

---

### Cloner un projet

```bash
git clone URL_DU_REPO
```

---

## Pourquoi GitHub est important ?

GitHub est devenu la plateforme de référence pour les développeurs. Il permet de démontrer ses compétences, de collaborer sur des projets open source et de constituer un portfolio technique visible par les recruteurs.

Dans le cadre de mon parcours à Akieni Academy, GitHub sera utilisé pour publier tous les projets réalisés au cours de la formation.
