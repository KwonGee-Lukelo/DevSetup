# Notes sur le Terminal

## Qu'est-ce que le terminal ?

Le terminal est une interface en ligne de commande (CLI - Command Line Interface) qui permet d'interagir directement avec le système d'exploitation à l'aide de commandes textuelles.

Le terminal est un outil indispensable pour les développeurs, car il permet d'automatiser des tâches, de manipuler des fichiers, d'utiliser Git, Node.js et de nombreux autres outils.

---

## Commandes de base

### Afficher le dossier courant

```bash
pwd
```

Affiche le chemin du répertoire actuel.

---

### Lister les fichiers

```bash
ls
```

Affiche le contenu du dossier courant.

---

### Changer de dossier

```bash
cd nom-du-dossier
```

Exemple :

```bash
cd Desktop
```

---

### Revenir au dossier précédent

```bash
cd ..
```

---

### Créer un dossier

```bash
mkdir mon-dossier
```

---

### Créer un fichier

```bash
touch index.html
```

---

### Supprimer un fichier

```bash
rm fichier.txt
```

---

### Effacer le terminal

```bash
clear
```

ou sous Windows

```bash
cls
```

---

## Pourquoi apprendre le terminal ?

- Plus rapide que l'interface graphique
- Utilisé dans les serveurs Linux
- Indispensable pour Git
- Utilisé dans les projets Node.js
- Compétence essentielle en développement Fullstack
